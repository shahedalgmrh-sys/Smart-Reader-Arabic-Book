# وثائق قاعدة البيانات (جداول + دوال) — API_Database_Gradution_project

هذه الوثيقة توثق **كل الجداول الموجودة** في قاعدة البيانات كما هي معرفة في طبقة ORM (SQLAlchemy)، وتربط كل جدول بالدوال البرمجية المقابلة له في طبقة البيانات (CRUD) داخل المشروع.

## ملاحظة مهمة حول (Stored Procedures / Functions / Triggers)

هذا المشروع لا يحتوي على **Stored Procedures** أو **Database Functions** أو **Triggers** مكتوبة داخل قاعدة البيانات (لا توجد ملفات SQL ولا عبارات `CREATE TRIGGER/PROCEDURE/FUNCTION` ضمن مجلد التطبيق).  
بدلاً من ذلك، يتم تنفيذ المنطق عبر **دوال Python** (Application-layer Functions) تعمل فوق SQLAlchemy.  
لذلك سيكون **نوع الدالة** في هذا المستند: `Application Function (Python)`، مع ذكر الملف الذي يحتويها.

## 1) جدول User

**اسم الجدول:** `User`  
**وظيفته:** تخزين بيانات المستخدم وربطها بـ `deviceId` كهوية فريدة للجهاز، وربط المستخدم بكتبه (PdfBook) وتقدّم القراءة (Position).

**أهم الحقول:**
- `userId` (PK)
- `nickName`
- `deviceId` (Unique, Indexed)
- `createdAt`

**العلاقات:**
- User (1) → (N) PdfBook عبر `PdfBook.userId`
- User (1) → (N) Position عبر `Position.userId`

### الدالة: get_or_create_user_by_device

- **النوع:** Application Function (Python)
- **المكان:** `app/crud.py`
- **المعلمات المدخلة:**
  - `db: Session`
  - `device_id: str`
  - `nickname: Optional[str] = None`
- **القيمة المرتجعة:** `User`
- **الوصف:** تبحث عن المستخدم عبر `deviceId`، وإن لم يوجد تنشئ مستخدمًا جديدًا وتعيده.

```python
def get_or_create_user_by_device(db: Session, device_id: str, nickname: Optional[str] = None) -> User:
    user = db.query(User).filter(User.deviceId == device_id).first()
    if user:
        return user
    user = User(
        deviceId=device_id,
        nickName=nickname or f"user_{device_id}" if device_id else "anonymous_user",
        createdAt=datetime.utcnow(),
    )
    db.add(user)
    db.commit()
    db.refresh(user)
    return user
```

### الدالة: update_book_audio

- **النوع:** Application Function (Python)
- **المكان:** `app/crud.py`
- **المعلمات المدخلة:**
  - `db: Session`
  - `book_id: int`

- **القيمة المرتجعة:** `PdfBook`
- **الوصف:** تُنشئ/تحدّث سجل AudioBook المرتبط بكتاب محدد، وتُحدّث `PdfBook.audioId`، وتكتب `AudioBook.fileHash` إن أمكن.

```python
def update_book_audio(db: Session, book_id: int, audio_path: str):
    db_book = (
        db.query(PdfBook)
        .options(selectinload(PdfBook.audio), selectinload(PdfBook.user), selectinload(PdfBook.positions))
        .filter(PdfBook.bookPdfId == book_id)
        .first()
    )
    if db_book:
        filename = os.path.basename(audio_path or "") or f"book_{book_id}.wav"
        if db_book.audio:
            db_book.audio.filePath = audio_path
            db_book.audio.fileName = filename
            try:
                with open(audio_path, "rb") as f:
                    db_book.audio.fileHash = compute_file_hash_stream(f)
            except Exception:
                pass
        else:
            audio = AudioBook(fileName=filename, filePath=audio_path, createdAt=datetime.utcnow())
            db.add(audio)
            db.flush()
            try:
                with open(audio_path, "rb") as f:
                    audio.fileHash = compute_file_hash_stream(f)
            except Exception:
                pass
            db_book.audioId = audio.audioId
        if db_book.fileChecksum:
            archive = get_archive_by_checksum(db, db_book.fileChecksum)
            if archive and not archive.audioId:
                archive.audioId = db_book.audioId
        db.commit()
        db.refresh(db_book)
    return db_book
```

### الدالة: set_book_audio_from_existing_path

- **النوع:** Application Function (Python)
- **المكان:** `app/crud.py`
- **المعلمات المدخلة:**
  - `db: Session`
  - `book: PdfBook`
  - `source_audio_path: str`
- **القيمة المرتجعة:** `PdfBook`
- **الوصف:** تربط كتابًا قائمًا بملف صوت موجود مسبقًا عبر `AudioBook.filePath`، أو تنشئ AudioBook جديدًا إن لم يوجد.

```python
def set_book_audio_from_existing_path(db: Session, book: PdfBook, source_audio_path: str):
    if not source_audio_path:
        return book
    filename = os.path.basename(source_audio_path) or f"book_{book.bookPdfId}.wav"
    audio = db.query(AudioBook).filter(AudioBook.filePath == source_audio_path).first()
    if not audio:
        audio = AudioBook(fileName=filename, filePath=source_audio_path, createdAt=datetime.utcnow())
        db.add(audio)
        db.flush()
    book.audioId = audio.audioId
    db.commit()
    db.refresh(book)
    return book
```

**فهارس (Indexes) مضافة:**
- `ix_pdfbook_user_name_author` على `(userId, bookPdfName, bookPdfAuthor)`
- `ix_pdfbook_user_filechecksum` على `(userId, fileChecksum)`

**العلاقات:**
- PdfBook (N) → (1) User
- PdfBook (N) → (1) AudioBook

### الدالة: create_book

- **النوع:** Application Function (Python)
- **المكان:** `app/crud.py`
- **المعلمات المدخلة:** كما في الكود
- **القيمة المرتجعة:** `PdfBook`
- **الوصف:** تنشئ كتابًا جديدًا للمستخدم (حسب deviceId). قبل الإنشاء تتحقق من وجود كتاب بنفس `checksum` (مع دعم عدة hashes v1/v2) لمنع التكرار، ثم تنشئ صف Position افتراضي.

```python
def create_book(
    db: Session,
    title: str,
    author: str,
    content: str,
    description: str = None,
    cover_image: str = None,
    device_id: str = None,
    file_checksum: str = None,
    file_format: str = None,
    file_path: str = None,
):
    device_value = device_id or ""
    content_hashes = compute_text_hashes(content or "")
    content_hash = content_hashes[0]

    user = get_or_create_user_by_device(db, device_value)

    existing_book = (
        db.query(PdfBook)
        .options(selectinload(PdfBook.user), selectinload(PdfBook.audio), selectinload(PdfBook.positions))
        .filter(
            PdfBook.userId == user.userId,
            PdfBook.deletedAt.is_(None),
            PdfBook.checksum.in_(content_hashes),
        )
        .order_by(PdfBook.bookPdfId.desc())
        .first()
    )
    if existing_book:
        if existing_book.checksum != content_hash:
            existing_book.checksum = content_hash
            if file_checksum and not existing_book.fileChecksum:
                existing_book.fileChecksum = file_checksum
            if file_format and not existing_book.fileFormat:
                existing_book.fileFormat = file_format
            if file_path and not existing_book.filePath:
                existing_book.filePath = file_path
            db.commit()
            db.refresh(existing_book)
        return existing_book

    db_book = PdfBook(
        bookPdfName=title,
        bookPdfAuthor=author,
        content=content,
        description=description,
        cover_image=cover_image,
        checksum=content_hash,
        fileChecksum=file_checksum,
        fileFormat=file_format,
        filePath=file_path,
        userId=user.userId,
    )
    db.add(db_book)
    db.commit()
    db.refresh(db_book)
    ensure_position_row(db, db_book, user.userId, 1)
    db.refresh(db_book)
    return db_book
```

### الدالة: ensure_position_row

- **المعلمات:** `db: Session`, `book: PdfBook`, `user_id: int`, `new_position: int`

- **الوصف:** تنشئ صف Position إذا لم يوجد، أو تحدّثه إذا كان موجودًا.

```python
def ensure_position_row(db: Session, book: PdfBook, user_id: int, new_position: int) -> Position:
    row = (
        db.query(Position)
        .filter(Position.userId == user_id, Position.pdfBookId == book.bookPdfId)
        .first()
    )
    if row:
        row.position = new_position
        row.updateDate = datetime.utcnow()
    else:
        row = Position(
            userId=user_id,
            pdfBookId=book.bookPdfId,
            position=new_position,
            createdAt=datetime.utcnow(),
            updateDate=datetime.utcnow(),
        )
        db.add(row)
    db.commit()
    return row
```

### الدالة: upsert_archive

- **النوع:** Application Function (Python)

```python
def upsert_archive(
    db: Session,
    file_checksum: str,
    file_format: str,
    file_path: str,
    file_size: int,
    title: str,
    author: str,
    description: str,
    content: str,
    cover_image: str,
    content_hash: str,
    audio_id: int = None,
):
    archive = get_archive_by_checksum(db, file_checksum)
    if archive:
        if audio_id and not archive.audioId:
            archive.audioId = audio_id
        if not archive.archivedAt:
            archive.filePath = file_path
        archive.fileSize = file_size or archive.fileSize
        archive.fileFormat = file_format or archive.fileFormat
        archive.bookPdfName = title or archive.bookPdfName
        archive.bookPdfAuthor = author or archive.bookPdfAuthor
        archive.description = description if description is not None else archive.description
        archive.cover_image = cover_image or archive.cover_image
        archive.content = content if content is not None else archive.content
        archive.contentHash = content_hash or archive.contentHash
    else:
        archive = BookArchive(
            fileChecksum=file_checksum,
            fileFormat=file_format,
            filePath=file_path,
            fileSize=file_size,
            bookPdfName=title,
            bookPdfAuthor=author,
            description=description,
            cover_image=cover_image,
            content=content,
            contentHash=content_hash,
            audioId=audio_id,
        )
        db.add(archive)
    db.commit()
    db.refresh(archive)
    return archive
```

```python
def mark_archive_archived_if_no_active_books(db: Session, file_checksum: str):
```

```python
def create_book_from_archive(db: Session, archive: BookArchive, device_id: str) -> PdfBook:
```

### الدالة: get_restore_logs_by_user

- **النوع:** Application Function (Python)
- **المكان:** `app/crud.py`
- **المعلمات:** `db: Session`, `user_id: int`, `limit: int = 20`, `offset: int = 0`
- **القيمة المرتجعة:** `(items: list[dict], total: int)`
- **الوصف:** تعيد لوج الاستعادات للمستخدم مع معلومات من BookArchive.

```python
def get_restore_logs_by_user(db: Session, user_id: int, limit: int = 20, offset: int = 0):
    total = db.query(func.count(BookRestoreLog.restoreId)).filter(BookRestoreLog.userId == user_id).scalar() or 0
    rows = (
        db.query(BookRestoreLog, BookArchive)
        .join(BookArchive, BookArchive.archiveId == BookRestoreLog.archiveId)
        .filter(BookRestoreLog.userId == user_id)
        .order_by(BookRestoreLog.restoredAt.desc())
        .offset(offset)
        .limit(limit)
        .all()
    )
    items = []
    for log_row, archive in rows:
        items.append(
            {
                "restored_at": log_row.restoredAt,
                "file_checksum": archive.fileChecksum,
                "file_format": archive.fileFormat,
                "title": archive.bookPdfName,
                "author": archive.bookPdfAuthor,
                "audio_available": bool(archive.audioId),
            }
        )
    return items, total
```

## 7) تهيئة قاعدة البيانات وإنشاء الجداول (Database Bootstrap)

**المكان:** `app/database.py`  
**الوصف:** يحدد `DATABASE_URL` (SQLite افتراضيًا) ويشغّل `Base.metadata.create_all()` لإنشاء الجداول عند بدء التشغيل.  
كما توجد ترقيات بسيطة لـ SQLite عبر `ALTER TABLE` لإضافة أعمدة إذا كانت ناقصة (هذا ليس Trigger ولا Migration Framework، بل ترقيات يدوية مبسطة).

```python
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, declarative_base
import os
import pathlib
from dotenv import load_dotenv

load_dotenv()

# Ensure SQLite database path is stable regardless of process CWD
_PROJECT_ROOT_DIR = pathlib.Path(__file__).resolve().parent.parent
_SQLITE_DB_PATH = _PROJECT_ROOT_DIR.joinpath("app.db").resolve()
_SQLITE_URL = f"sqlite:///{_SQLITE_DB_PATH.as_posix()}"

# Prefer environment variable, but safely fallback to SQLite if driver missing
_env_url = os.getenv("DATABASE_URL")
if _env_url:
    try:
        if _env_url.startswith("postgres"):
            import psycopg2  # type: ignore
        DATABASE_URL = _env_url
    except Exception:
        DATABASE_URL = _SQLITE_URL
else:
    DATABASE_URL = _SQLITE_URL

# For SQLite, ensure proper connect args; for Postgres, set short connect timeout
if DATABASE_URL.startswith("sqlite"):
    connect_args = {"check_same_thread": False, "timeout": 30}
elif DATABASE_URL.startswith("postgres"):
    connect_args = {"connect_timeout": int(os.getenv("DB_CONNECT_TIMEOUT", "5"))}
else:
    connect_args = {}
engine = create_engine(DATABASE_URL, pool_pre_ping=True, connect_args=connect_args)
SessionLocal = sessionmaker(bind=engine, autocommit=False, autoflush=False, expire_on_commit=False)

Base = declarative_base()

# Create tables automatically on startup
try:
    # Import models after Base is defined to avoid circular import issues
    from app import models  # noqa: F401
    Base.metadata.create_all(bind=engine)
    if DATABASE_URL.startswith("sqlite"):
        with engine.begin() as conn:
            def _cols(table: str) -> set[str]:
                rows = conn.exec_driver_sql(f"PRAGMA table_info('{table}')").fetchall()
                return {r[1] for r in rows}

            def _add_col(table: str, col: str, ddl_type: str):
                conn.exec_driver_sql(f"ALTER TABLE {table} ADD COLUMN {col} {ddl_type}")

            pdf_cols = _cols("PdfBook")
            if "fileChecksum" not in pdf_cols:
                _add_col("PdfBook", "fileChecksum", "VARCHAR")
            if "fileFormat" not in pdf_cols:
                _add_col("PdfBook", "fileFormat", "VARCHAR")
            if "filePath" not in pdf_cols:
                _add_col("PdfBook", "filePath", "VARCHAR")
            if "deletedAt" not in pdf_cols:
                _add_col("PdfBook", "deletedAt", "DATETIME")

            audio_cols = _cols("AudioBook")
            if "fileHash" not in audio_cols:
                _add_col("AudioBook", "fileHash", "VARCHAR")
except Exception:
    # Table creation will be deferred; routes will trigger creation on first DB use if needed
    pass
```
